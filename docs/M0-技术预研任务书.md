## 一、目标与出口标准

| 原型 | 验证的风险 | 出口标准（全部达标才算通过） |
|------|-----------|------------------------------|
| A：TextKit II 大文件 | RK-01 大文件性能不达预期 | 52MB JSON 打开 ≤2s；滚动/跳转无可感知卡顿；内存 ≤500MB；200MB 日志只读降级不冻结 |
| B：多行标签自绘 | RK-02 自绘控件交互复杂 | 30 标签 3 行布局正确；跨行拖拽排序正确；增删/切换流畅；3 行上限对极端数量生效 |

## 三、原型 A：TextKit II 大文件性能

### 3.1 实现要点（具体接入方式以开发实测为准）

- SwiftUI 窗口 + `NSViewRepresentable` 包裹 `NSTextView`；启用 TextKit II（`NSTextContentStorage` / `NSTextLayoutManager` 管线，macOS 12+ 可用）——注意 SwiftUI 自带 `TextEditor` 是 TextKit 1，不要直接用
- 只需实现：打开文件按钮（或命令行传入路径）、文本展示、行跳转（简单实现：直接设置滚动位置即可）
- 无需实现高亮、撤销、编码（都不在本原型范围）

### 3.2 实测项

| # | 实测项 | 操作步骤 | 达标阈值 | 实测值（3 次中位数） | 达标 |
|---|--------|----------|----------|---------------------|------|
| A-1 | 52MB JSON 打开 | 启动原型 → 打开 `big_50mb.json`，从点击到可滚动 | ≤ 2s | | ☐ |
| A-2 | 滚动流畅度 | 滚到文件中部，持续滚动 30s，Time Profiler 观察主线程 | 无 >100ms 单帧（无可感知卡顿） | | ☐ |
| A-3 | 行跳转 | 跳转第 1 行 / 最后 1 行 / 中部随机行，各 3 次 | 每次响应 ≤ 200ms（估算） | | ☐ |
| A-4 | 编辑响应 | 中部位置连续输入字符 100 次 | 输入到渲染无可感知延迟 | | ☐ |
| A-5 | 内存占用 | 加载 52MB 文件后静置 1 分钟读 Memory Gauge | ≤ 500MB | | ☐ |
| A-6 | 200MB 只读 | 打开 `huge_200mb.log`（可临时按只读处理，不要求做 FR-12 完整功能） | 不冻结、可滚动（着色不做） | | ☐ |
| A-7 | 1MB 格式化（选做） | `JSONSerialization` 反序列化 `small_1mb.json` + 2 空格重新序列化（验证 FR-05 的 0.5s 阈值参考值） | ≤ 0.5s | | ☐ |

### 3.3 判定分支

- **A-1~A-5 全达标** → RK-01 关闭，PRD 性能指标由估算转实测
- **A-1 或 A-2 不达标** → 启动降级预案：分块加载（只加载视口附近 ± N 行，NSTextContentStorage 支持按需供给）+ 只读模式，降级方案需再做一轮 A-1/A-2 实测
- **A-6 不达标** → 排期时把 FR-12 阈值下调（20MB → 10MB）或将 200MB 场景明确为不支持、提示用户用外部工具

## 四、原型 B：多行标签自绘控件

### 4.1 实现要点

- 纯 UI 原型：一个窗口 + 标签条，30 个假标签（文件名 a.json ~ ad.json 之类），标签宽度基准 160px（含图标位/文件名/脏标记/关闭按钮，与 PRD FR-02 口径一致）
- 实现方式自选：SwiftUI 布局（按行分组 + `ScrollView` 横向）或 AppKit 自绘均可，以能验证交互为准
- 必须实现：换行布局计算、关闭按钮、拖拽排序（SwiftUI `.draggable`/`.dropDestination` 或 AppKit 鼠标事件）、行高变化动画

### 4.2 实测项

| # | 实测项 | 操作步骤 | 达标阈值 | 实测值 | 达标 |
|---|--------|----------|----------|--------|------|
| B-1 | 换行布局 | 1200px 宽窗口放 30 个标签：预期前 2 行各 7 个（1200÷160），第 3 行 16 个横向滚动并显示溢出计数 | 布局与预期一致，无错位 | | ☐ |
| B-2 | 跨行拖拽 | 第 1 行标签拖到第 3 行中部松手，重复 10 次 | 排序生效、无跳位、无幽灵标签 | | ☐ |
| B-3 | 增删切换流畅度 | 连续开/关标签 30 次 + 快速点击切换 | 无可感知卡顿 | | ☐ |
| B-4 | 行高动画 | 跨 1→2→3 行边界增删标签 | 高度过渡平滑，无跳变 | | ☐ |
| B-5 | 极端数量 | 加到 100+ 个标签 | 3 行上限生效，编辑区高度不被压缩 | | ☐ |
| B-6 | 窗口缩放 | 宽度在 600~1600px 间连续拖动窗口 | 换行实时重排，无闪烁 | | ☐ |

### 4.3 判定分支

- **全达标** → RK-02 关闭，FR-02 进入正式开发
- **B-2/B-4 不达标** → 降级选项 1：拖拽仅支持同行内排序（跨行用右键菜单移动），其余保留
- **B-1/B-5 不达标** → 降级选项 2：单行 + 溢出下拉列表——此选项**损害核心卖点**，必须回到产品评审重新评估，不允许开发侧自行决定
